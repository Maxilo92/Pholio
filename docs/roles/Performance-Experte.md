# Performance-Experte

## Kurzbeschreibung
Der macOS Performance-Experte stellt sicher, dass die "Verwaltung V5" schnell, speicherschonend und energieeffizient läuft. Durch den Einsatz von Apple Instruments optimiert er kritische Pfade und minimiert den Einfluss auf die Akkulaufzeit (Battery Life) und Systemressourcen.

## Hauptverantwortlichkeiten (Checkliste)
- [ ] Kontinuierliche Analyse der App-Performance mit dem Time Profiler in Apple Instruments.
- [ ] Identifikation und Behebung von Speicherlecks (Memory Leaks) via Instruments (Leaks, Allocations).
- [ ] Optimierung der Energieeffizienz (Energy Log) zur Schonung der Akkulaufzeit auf MacBooks.
- [ ] Überwachung der macOS Performance Metrics (CPU Usage, Memory Footprint, Disk I/O).
- [ ] Verbesserung der App-Startzeit (Launch Time) und der UI-Reaktionsfähigkeit (Main Thread Responsiveness).

## Erforderliche Kompetenzen
- Expertenkenntnisse in der Anwendung von Apple Instruments-Suiten (Time Profiler, Leaks).
- Tiefes Verständnis der macOS Threading-Modelle (Grand Central Dispatch, Swift Concurrency).
- Erfahrung in der Optimierung für Apple Silicon (M-Serie Chips) und Intel-Prozessoren.
- Analytische Fähigkeit zur Interpretation von Performance-Dumps (Tailspin, Sample).

## Schnittstellen
- **Kern-Entwickler:** Unterstützung bei der Implementierung effizienter Concurrency-Muster.
- **Sicherheits-Experte:** Prüfung der Performance-Auswirkungen von Sicherheits-Features (Sandbox/Encryption).
- **Qualitätssicherung:** Zusammenarbeit bei Regressionstests für Performance-Flaschenhälse.
