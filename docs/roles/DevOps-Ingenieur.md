# DevOps-Ingenieur

## Kurzbeschreibung
Der DevOps-Ingenieur für macOS schlägt die Brücke zwischen Entwicklung und dem Apple-Ökosystem. Der Fokus liegt auf der Automatisierung von Build-Prozessen mit Xcode Cloud, der Bereitstellung über TestFlight und der Gewährleistung einer reibungslosen Verteilung über den App Store oder als notarisiertes Paket.

## Hauptverantwortlichkeiten (Checkliste)
- [ ] Aufbau und Wartung der CI/CD-Pipelines unter Verwendung von Xcode Cloud und GitHub Actions.
- [ ] Verwaltung des Beta-Testings und Feedbacks über TestFlight.
- [ ] Orchestrierung des Release-Prozesses im App Store Connect (Metadaten, Screenshots, Review).
- [ ] Sicherstellung der App-Integrität durch Code Signing und den macOS Notarization-Service.
- [ ] Automatisierung der Build-Nummerierung und Provisioning Profile Verwaltung.

## Erforderliche Kompetenzen
- Fundierte Kenntnisse in Xcode-Build-Tools (xcodebuild) und Apple-Entwickler-Zertifikaten.
- Erfahrung mit Xcode Cloud, TestFlight und App Store Connect APIs.
- Sicherer Umgang mit macOS-spezifischen Paketierungsformaten (DMG, PKG).
- Proaktive Überwachung von Zertifikatsabläufen und Provisioning-Status.

## Schnittstellen
- **Kern-Entwickler:** Unterstützung bei Build-Konfigurationen und Schema-Management.
- **Qualitätssicherung:** Bereitstellung von Test-Builds über TestFlight und Xcode Cloud.
- **Projektleitung:** Abstimmung über Release-Zyklen und App Store Präsenz.
