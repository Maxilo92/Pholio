# Technischer Autor

## Kurzbeschreibung
Der macOS Technische Autor ist verantwortlich für die native Dokumentationserfahrung der "Verwaltung V5". Er gestaltet verständliche Hilfeinhalte im Apple-Stil, pflegt das macOS Help Book (Help Viewer) und erstellt präzise Release Notes für das macOS-Ökosystem.

## Hauptverantwortlichkeiten (Checkliste)
- [ ] Erstellung und Pflege des macOS Help Books zur Anzeige im Help Viewer.
- [ ] Gestaltung der Hilfeinhalte im Apple-Stil (Sprache, Klarheit, Struktur).
- [ ] Verfassen von macOS-spezifischen Release Notes für den App Store und In-App-Updates.
- [ ] Erstellung von Onboarding-Guides für macOS-spezifische Features wie Widgets und Shortcuts.
- [ ] Validierung der Hilfesystem-Integration in der Menüleiste ("Hilfe"-Menü).

## Erforderliche Kompetenzen
- Exzellente schriftliche Ausdrucksfähigkeit gemäß Apple Style Guide.
- Erfahrung mit dem macOS Help Book Format (HTML/CSS-Struktur, Apple Help Tags).
- Verständnis für macOS-Benutzeroberflächen-Terminologie (z.B. Menüleiste, App-Icon, Dock).
- Sicherer Umgang mit Xcode-Hilfe-Referenzen und Markdown.

## Schnittstellen
- **Kern-Entwickler:** Einholen technischer Details für neue macOS-Funktionen.
- **Qualitätssicherung:** Validierung der Hilfetexte auf Apple HIG-Konformität.
- **Integrations-Lead:** Dokumentation von Shortcuts-Aktionen und Widget-Optionen.
